# Agents proposent, l'humain décide

<div class="mt-6 text-lg space-y-6">

- Tout mon outillage IA est **read-only par défaut** ; `build` est le seul à écrire. Pas un accident : <b>c'est la règle dont tout le reste découle.</b>
- **Tout code généré est votre code.** Le modèle a écrit, mais votre nom est sur le commit. Aucune ligne n'échappe à la *review*.
- **On investit avant que le code existe** : je lis les plans entièrement, je discute, je pousse en retour, j'ajuste les prompts d'agents — la review finale est courte *parce que* le travail a été fait en amont.

</div>

<div class="mt-8 rounded-lg bg-#2b2b2a text-white p-6 text-xl">
C'est mon contrepoint au courant « YOLO agents » qui laisse un agent galoper avec toutes les permissions.
</div>
