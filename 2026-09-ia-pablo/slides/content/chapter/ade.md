# Enter the ADE

An **Agent Development Environment** is not "an IDE with an AI panel bolted on".

<div class="grid grid-cols-2 gap-8 mt-4">

<div>

### IDE

- Primitives: **files & buffers**
- One developer, one working copy, one thread of work

### ADE

- Primitives: **tasks, worktrees, agents**
- You orchestrate **several at once**

</div>

<div class="text-base">

**It is already out there**

- <mdi-cursor-default-outline class="text-[#e9ce37]"/> **Cursor 2.0** hides the file tree: what remains is a conversation with an agent
- <mdi-source-branch class="text-[#e9ce37]"/> **Jean** ships native git worktree management: one isolated worktree per task
- <mdi-view-dashboard-outline class="text-[#e9ce37]"/> **Orca** adds Jira & Linear integration, a kanban board *(Todo / Waiting / In progress / Draft)* and a right dock: file explorer, agent sessions, git, GitHub Actions runs

</div>

</div>

<div class="mt-4 text-base opacity-80">
Nothing is lost: agents, commands, skills all carry over — the ADE stands <b>on top of that toolbox</b>.
</div>
